# 🎮 Simon Says Game

A fun and interactive web-based memory game inspired by the classic **Simon Says** game. The player must remember the sequence of flashing colored buttons and repeat the sequence correctly to advance through increasingly difficult levels.

🔗 **Live Demo:** https://itissv.github.io/Simon-Says-Game/

---

## ✨ Features

- 🧠 **Memory Challenge:** Remember the sequence of colored buttons and repeat it correctly.

- 🎮 **Interactive Game Buttons:** Click the colored buttons to enter your answer.

- 📈 **Increasing Difficulty:** The sequence becomes longer as you progress through each level.

- 🏆 **High Score:** The game keeps track of your highest score during the session.

- 💥 **Game Over Detection:** The game ends immediately when an incorrect button is selected.

- 🔄 **Restart Game:** Press any key after Game Over to start a new game.

- ✨ **Visual Feedback:** Buttons flash with animations when the game generates a sequence or when the player selects a button.

- 📱 **Responsive Design:** The interface adjusts for different screen sizes, including mobile devices.

- 🎨 **Modern UI:** Dark glassmorphism-inspired interface with glowing buttons and animations.

---

## 🎯 How to Play

1. Open the game using the **Live Demo**.

2. Press any key to start the game.

3. Watch carefully as one of the colored buttons flashes.

4. Click the button that flashed.

5. In the next level, remember the previous sequence and the new button.

6. Repeat the complete sequence in the correct order.

7. Continue advancing through the levels.

8. If you click the wrong button, the game ends.

9. Press any key to restart and try to beat your high score!
